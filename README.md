# Network Lab Template

Welcome to the NEC Lab. This project uses `uv` for Python package management. 
Follow these steps carefully to set up your environment and submit your work.

## Step 1: Create your repository
1. Click the green **Use this template** button at the top right of this page.
2. Select **Create a new repository**.
3. Name it `nec-lab-YOURNAME` and click **Create repository**.
